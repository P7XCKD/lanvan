# Lanvan Documentation

This directory contains configuration requirements, platform setup files, and troubleshooting guides for running the Lanvan file sharing server in various environments.

## Directory Contents

* **[TERMUX_SETUP.md](./TERMUX_SETUP.md)**: Steps to install and configure the application on Android Termux without heavy library dependencies.
* **[iOS_SETUP.md](./iOS_SETUP.md)**: Setup instructions for iOS Safari client access, including self-signed certificate installation.
* **[ANDROID_TROUBLESHOOTING.md](./ANDROID_TROUBLESHOOTING.md)**: Common connection and runtime issues in Android environments.
* **[termux/](./termux/)**: Automated setup assets and scripts for Android Termux.
