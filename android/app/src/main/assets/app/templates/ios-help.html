iOS Safari Connection Help

Having trouble connecting to Lanvan on your iPhone or iPad? Follow these steps:

Step 1: Use HTTP (Recommended)

iOS Safari works best with HTTP on local networks. Try this URL first:

http://10.110.4.169:5000
Try HTTP Connection

Step 2: Alternative URLs

If the primary URL doesn't work, try these alternatives:

mDNS URL (if supported):

http://lanvan.local:5000

HTTPS (with security warning):

https://10.110.4.169:5001

For HTTPS, tap "Advanced" → "Continue to site" on security warnings

Step 3: Check Network Connection

Ensure your iPhone/iPad is connected to the same WiFi network as the server:

  • Check WiFi settings - should be connected to same network as server
  • Try turning WiFi off and back on
  • Check if you can browse other websites normally

Step 4: Clear Safari Cache

If the page won't load properly:

  1. Go to Settings → Safari
  2. Tap "Clear History and Website Data"
  3. Confirm by tapping "Clear"
  4. Try connecting again

Step 5: Handle Security Warnings

If using HTTPS and seeing security warnings:

  1. Tap "Show Details" or "Advanced"
  2. Tap "Visit this website" or "Continue to site"
  3. Confirm you want to continue

This is normal for self-signed certificates on local networks

Still Not Working?

Try these advanced troubleshooting steps:

  • Use Chrome or Firefox: Sometimes other browsers work better
  • Check router settings: Some routers block device-to-device communication
  • Guest network: If you're on a guest network, try the main network
  • VPN: Disable VPN if you're using one
  • Firewall: Check if the server's firewall is blocking connections
